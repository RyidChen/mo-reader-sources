# 墨讀來源規則

墨讀 Android 閱讀器使用的公開、已簽章來源設定。不包含漫畫、收藏、進度、登入資料或簽章私鑰。

- `source-rules.txt`：適用 Android 0.1.10／0.1.11 的 V1 圖片規則，保留舊格式。
- `source-rules-v2.txt`：適用 Android 0.1.12 起的 V2 規則，包含版本號、一個漫蛙站址及核准圖片主機。
- V2 簽章涵蓋格式標頭及內容，與 V1 分隔。App 內建公鑰驗證，拒絕較舊版本及同版本不同內容。
- 漫蛙站址僅開放 `/comic/數字`、`/api/comic/數字/chapters`、`/api/comic/image/數字`，不賦予任意頁面、登入／帳號接口或圖片權限。
- 圖片主機仍受既有路徑、格式、尺寸、容量檢查；所有網路連線保留 HTTPS、公開 IP 及逐次轉址驗證，不執行網站程式。

來源更新只套用程式已支援的規則，不能替舊 APK 增加它不支援的規則格式。網站接口結構、版型、解碼方式改變時仍可能需要新版 App。

本儲存庫僅發布維護者確認及簽署的設定；未持有私鑰者即使修改檔案，也無法產生 App 接受的有效簽章。
